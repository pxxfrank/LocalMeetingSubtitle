# 用户指南 — 字幕君 本地会议字幕

字幕君 在**本机**把系统正在播放的声音（会议、视频、网课等）实时转成中文字幕。
它**完全离线、纯 CPU 运行**，不需要麦克风，也不会把任何内容发到网上。

> 本指南对应**候选发布版本（待实机验收）**。在目标笔记本上完成验收前，延迟/资源占用等指标以实际使用为准。

---

## 1. 系统要求

- Windows 10 / 11（64 位）。
- 可正常播放声音的音频输出设备（扬声器 / 耳机）。
- 需要至少一个已下载的语音识别模型（见第 4 步）。模型较大，建议预留约 100 MB 以上磁盘空间。
- 便携版（自包含）无需单独安装 .NET 运行库。

## 2. 安装与首次启动

1. 解压发布包（例如 `字幕君-win-x64`）。
2. 双击 **`字幕君.exe`**。
3. 程序为**单实例**：若已在运行，再次启动会提示“已在运行”并退出。
4. 首次启动会自动创建用户数据目录：
   `%LOCALAPPDATA%\SubtitleJun\`（数据库、日志、模型、导出都在这里）。

程序启动后会显示主窗口，右上角显示状态（空闲 / 加载模型 / 就绪 / 转写中 / 已暂停 / 错误）。

## 3. 准备工作：安装语音模型（重要）

**没有安装模型时，“开始”按钮会保持灰色不可点**，状态栏会提示“模型未安装”。这是为了不产生任何假输出。

安装模型（在源码目录中，使用 PowerShell）：

```powershell
$env:PATH = "$env:USERPROFILE\.dotnet;$env:PATH"   # 若 .NET 不在 PATH
dotnet run --project tools/ModelManager -- install --id streaming-zipformer-zh-14M `
    --models-root "$env:LOCALAPPDATA\SubtitleJun\models"
```

也可以让维护者手动把模型文件放到
`%LOCALAPPDATA%\SubtitleJun\models\<模型目录>\` 下。
放好后重新打开程序（或重启程序），状态栏应显示“就绪”。

## 4. 主界面说明

主窗口从上到下、从左到右大致包含：

- **顶部信息栏**：状态、当前音频设备、模型名称与是否安装、端到端延迟、热词模式。
- **警告横幅**：出现问题时在顶部显示黄色提示，可点 **✕** 关闭（约 15 秒后自动消失）。
- **字幕区**：实时显示每一行字幕（时间戳 + 正文）。尚未定稿的“临时字幕”以斜体灰色显示。
- **底部操作栏**：开始 / 暂停 / 继续 / 停止 / 搜索 / 导出 / 设置 / 悬浮字幕 / 复制，以及音量电平条。
- **搜索栏**：点击“搜索”后出现。

## 5. 选择音频设备

- 顶部 **“音频设备 / Device”** 下拉框列出可捕获的播放设备；默认选中系统默认设备。
- 点击 **“刷新 / Refresh”** 可重新枚举设备（插拔耳机后可用）。
- **转写进行中不能切换设备**；请先停止再切换。

## 6. 开始 / 暂停 / 继续 / 停止

| 按钮 | 作用 |
| --- | --- |
| **开始 / Start** | 加载模型并开始捕获 + 转写。仅在“就绪/空闲”且模型已安装、已选设备时可用。 |
| **暂停 / Pause** | 暂停捕获；会把当前尚未定稿的一句话**补完并保存**，避免丢句。 |
| **继续 / Resume** | 从暂停处继续。 |
| **停止 / Stop** | 结束本次转写并保存会话。停止后仍可查看/导出本次字幕。 |

> 提示：先把会议/视频的**声音播放出来**，字幕才会出现。字幕来自“系统正在播放的声音”，不是麦克风。

## 7. 查看与回看完整字幕

- 每行开头显示该句的**开始时间**，格式为 **`[HH:MM]`**（分钟精度，界面不再显示秒）。
  导出的文件（TXT / Markdown / CSV / SRT）不受影响，仍带完整时间戳。
- 转写过程中视图默认**自动滚动**到最新一行。
- 当你用鼠标向上滚动查看历史时，会自动解除“跟随最新”，此时底部会出现
  **“↓ 返回最新字幕 / Return to latest”** 按钮；点击它回到最新一行。
- 可框选（多选）一行或多行，点击 **“复制 / Copy”** 复制所选内容。
- **注意**：目前只能按“整行”选择和复制，不能选中一行内的单个字/词。

## 8. 搜索

1. 点击 **“搜索 / Search”** 显示查找栏。
2. 输入关键字；匹配的整行会以黄色高亮，右侧显示匹配条数。
3. 再次点击“搜索”可隐藏查找栏。

## 9. 热词管理

热词用于提高专有名词（人名、术语、缩写等）的识别概率。

### 华为领域专业词表（内置，默认开启）

程序**内置了一份公开的华为领域术语表**（约 116 条，覆盖芯片与算力、操作系统、云与数据、网络与联接、终端、智能汽车、数字能源、流程与组织），在设置窗口的**「热词」**区域上方用 **「启用华为领域专业词表 / Enable Huawei-domain lexicon」** 勾选框控制（默认开启）。

开启后：
- 这些术语会与**你自己的热词合并**参与模型加权（你自己的同名条目优先）；
- 同时会加入一批**文本纠正规则**，修正常见的同音/近音误识别（例如 `升腾 → 昇腾`、`鲲朋 → 鲲鹏`、`鸿盟 → 鸿蒙`）。

> 说明：这份词表是**公开资料整理的通用词表，不是华为内部术语库**，也无法覆盖各团队的内部项目代号。建议把你们团队常用的术语**追加到热词框**里（一行一个）。
>
> 已知限制（见 [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) P3-11）：随包的中文模型对**部分纯英文缩写**（如 CANN、IPD、HCSO）和**个别生僻字**（如「昇」「崑」）没有词表项，这些词无法参与模型加权，只能靠**文本纠正规则**或改用更大的中英双语模型。

### 管理热词

1. 点击 **“设置 / Settings”** 打开设置窗口。
2. 在**热词**文本框中编辑，**一行一个热词**。
3. 点击 **“保存 / Save”** 生效。
   - 若正在转写：热词会在**下一句话**开始生效（引擎热切换，当前句子先保存）。
   - 若未转写：热词在**下次开始**时生效。
4. 顶部“热词 / Hotwords”会显示当前模式：
   - **模型级热词 / model-level**：热词真正参与识别（本机默认模型支持）。
   - **仅文本纠正 / text-correction**：模型不支持热词时，仅对结果做文本替换。
   - **不支持 / not supported**、**加载失败 / load failed**：提示相关问题。

> 当前热词界面是“一行一个”的简单文本框，没有专门的热词管理器（分组、逐条开关/权重），也没有独立的“从文件导入”按钮。若维护者需要批量导入，可先整理成这一行一个的格式再粘贴。

## 10. 悬浮字幕（置顶显示）

点击主界面的 **“悬浮字幕 / Floating”**（或托盘菜单）可显示/隐藏悬浮字幕窗口。它适合在全屏会议时叠在屏幕上方阅读。

- **置顶**：悬浮窗始终保持在其他窗口之上，且不出现在任务栏 / Alt-Tab，也不会抢走当前窗口的焦点。
- **拖拽移动**：按住悬浮窗任意位置即可拖动到合适位置。
- **字号**：在“设置”中调整“悬浮字幕字号”。
- **透明度**：在“设置”中调整“悬浮字幕背景透明度”（越接近 0 越透明）。
- **鼠标穿透**：在“设置”中勾选，或在**托盘菜单**中开启“悬浮字幕鼠标穿透”。开启后鼠标点击会“穿过”悬浮窗，不影响下面的操作。
- **恢复（关闭穿透）**：
  - 托盘菜单里再次点击“悬浮字幕鼠标穿透”取消勾选；或
  - 在悬浮窗上点右键，选择 **“禁用鼠标穿透 / Disable click-through”**；或
  - 在“设置”中取消勾选。
- 悬浮窗右键菜单还提供 **“隐藏 / Hide”**。

> 说明：悬浮窗的置顶与鼠标穿透已实现并经过代码验证；**窗口缩放的交互效果尚未逐一手动验证**。

## 11. 导出字幕

1. 点击 **“导出 / Export”**。
2. 在保存对话框中选择格式：
   - **文本 / Text (`*.txt`)**
   - **字幕 / SubRip (`*.srt`)**
   - **Markdown (`*.md`)**
3. 选择是否包含时间戳：在“设置”中的“导出包含时间戳”。
4. 导出文件默认建议保存到 `%LOCALAPPDATA%\SubtitleJun\exports\`，也可另存到任意位置。
5. 只有**已定稿**的字幕行会被导出（临时字幕不导出）。

## 12. 会后说话人分离（匿名发言人标签）

会议结束后，可以**导入一段录音**，让程序分析出「谁在什么时候说话」，并给每条字幕标上发言人标签（A、B、…）。

1. 先确认已下载**两个说话人分离模型**（与语音识别模型是分开的）。在源码目录执行：

   ```powershell
   $env:PATH = "$env:USERPROFILE\.dotnet;$env:PATH"   # 若 .NET 不在 PATH
   dotnet run --project tools/ModelManager -- install --id pyannote-segmentation-3-0 `
       --models-root "$env:LOCALAPPDATA\SubtitleJun\models"
   dotnet run --project tools/ModelManager -- install --id 3dspeaker-eres2net-base-zh-16k `
       --models-root "$env:LOCALAPPDATA\SubtitleJun\models"
   ```

   用 `dotnet run --project tools/ModelManager -- list` 可查看是否已安装（行首显示 `[x]` 即已安装）。
2. 回到主界面，点击底部操作栏的 **「说话人 / Speakers」** 按钮。
3. 在弹出的文件对话框中选择一个录音文件（支持 `wav` / `mp3` / `flac` / `m4a` / `aac` / `wma` / `aiff` / `ogg`）。
4. 分析在后台进行（底部会出现进度条），完成后每条字幕会显示**发言人标签**（A、B、C…），不同发言人用不同颜色区分。

> **重要：** 这里的 A / B / … 是**声纹聚类出的匿名编号**，只是把「听起来像同一个人的片段」聚在一起，
> **不是身份识别**，不代表真实姓名或身份。分析完成后仍需你人工判断谁说了哪句。
>
> 说话人分离在**后台低优先级线程**上运行，一次只跑一个，不会影响正在进行的实时转写。

> 目前还没有「重命名发言人 / 合并发言人 / 逐条改派」的界面，也**没有专门的人数开关**：期望人数与聚类阈值来自设置项 `DiarizationSpeakerCount`（0 = 自动，默认）和 `DiarizationClusteringThreshold`（默认 0.5）。这些功能计划在后续版本补齐。详见 [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) 的 P3-6 / P3-7。

## 13. 托盘操作

程序最小化后在**通知区域（托盘）**有图标，**双击**可重新打开主窗口。右键菜单包含：

- **状态 / Status**：显示当前状态（不可点）。
- **打开主窗口 / Open main window**
- **开始 / 暂停 / 继续**：随当前状态变化。
- **停止 / Stop**
- **显示/隐藏悬浮字幕**
- **悬浮字幕鼠标穿透**（勾选开关）
- **设置 / Settings**
- **退出 / Exit**

> 默认情况下，点击主窗口右上角的“关闭”是**最小化到托盘**（不退出）。要真正退出，请用托盘菜单的“退出”。

## 14. 退出

- **托盘菜单 →“退出 / Exit”**：会先优雅地停止转写、保存后退出。
- 直接关闭主窗口只是隐藏到托盘；程序仍在后台运行。

## 15. 数据与隐私

- 所有数据都在本机 `%LOCALAPPDATA%\SubtitleJun\`：
  - `subtitles.db`：会话、字幕、热词、设置、性能指标（SQLite，WAL 模式）。
  - `logs\`：运行日志。
  - `models\`：语音模型。
  - `exports\`：导出文件。
- 运行时**不联网**：识别链路不包含任何网络调用（可由 `tools/OfflineVerification` 校验）。

## 16. 排查：没有声音 / 没有字幕

按顺序检查：

1. **确认系统确实在出声**：先播放一段有声音的音频，确认扬声器/耳机有声音且**未静音**。本工具捕获的是“正在播放的声音”。
2. **确认选择了正确的音频设备**：在顶部下拉框中选“默认设备”或实际的输出设备；必要时点“刷新”。若下拉框为空，状态栏/警告会提示“未发现可捕获的音频设备”，请检查系统音频输出。
3. **确认模型已安装**：状态栏应显示“就绪 / Ready — <模型名>”。若显示“模型未安装”，请按第 3 步安装模型；“开始”按钮此时是灰色，属正常。
4. **确认“开始”已点击且状态为“转写中”**：只有“转写中 / Transcribing”才会产生字幕。
5. **看底部“音量电平条”**：播放声音时电平条应有起伏。若电平条不动，说明**没有捕获到声音**（设备选错 / 系统静音 / 该应用用了独占音频）。
6. **看顶部警告横幅**：出现“音频积压超过 … 秒、已丢弃音频”等提示时，说明机器识别跟不上，字幕会滞后或丢字，可尝试降低会议音频负载或换更强的机器。
7. **长句不出现**：识别在“断句”后才定稿为最终字幕；临时（斜体）字幕一直在更新，说明正在识别中，稍等即可。
8. **仍无输出**：查看 `%LOCALAPPDATA%\SubtitleJun\logs\` 下的日志，寻找 `ASR decode failed` / `audio capture failed` / `native library` 等关键字。

> 若日志提示 **“未找到 sherpa-onnx 原生库 / native library missing”**，说明缺少 `sherpa-onnx-c-api.dll` / `onnxruntime.dll`（发布包应自带，请勿删除）。
